## 📌 Sobre o projeto

Este projeto tem como objetivo desenvolver um dashboard para acompanhamento de uma operação industrial fictícia.

A solução será construída para organizar dados produtivos e transformar registros operacionais em informações úteis para acompanhamento de metas e tomada de decisão.

O projeto faz parte do meu portfólio de desenvolvimento em **dados, automação e dashboards industriais**.

## 🏭 Contexto fictício

O cenário representa uma empresa industrial fictícia que precisa acompanhar sua produção ao longo de diferentes dias, turnos e linhas produtivas.

Os dados utilizados serão criados exclusivamente para este projeto e não representam informações, produtos ou processos internos de nenhuma empresa real.

## 🎯 Objetivos

- Comparar a produção realizada com a meta planejada;
- Acompanhar a eficiência produtiva;
- Identificar perdas e possíveis gargalos;
- Comparar o desempenho entre turnos;
- Facilitar a leitura dos resultados;
- Apoiar decisões por meio de indicadores visuais.

## 📈 Indicadores planejados

- Produção planejada;
- Produção realizada;
- Percentual de atingimento da meta;
- Eficiência produtiva;
- Quantidade de perdas;
- Índice de perdas;
- Produção por turno;
- Produção por linha;
- Principais motivos de parada;
- Evolução da produção ao longo do tempo.

## 🛠️ Ferramentas planejadas

- Microsoft Excel;
- Power BI;
- Git e GitHub;
- Dados fictícios em formato CSV ou XLSX.

## 🔒 Segurança dos dados

Todos os nomes, valores, metas, produtos, processos e resultados apresentados neste repositório serão fictícios.

O projeto utiliza apenas conceitos gerais de gestão da produção e não contém dados confidenciais de empresas reais.
